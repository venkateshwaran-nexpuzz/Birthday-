Hema Birthday Website — Updated with Personal Birthday Animation

The website is in English, except for the personal friendship letter, which is in Thanglish. VENKY is credited as Hema's friend.

Included features:
- Birthday cake and candle wish interaction
- Friendship cards and personal note
- Gentle decorations and reduced visual effects
- A locally stored animated birthday greeting for Hema (no YouTube embed required)
- Responsive layout for mobile and desktop

Run locally:
1. Extract the ZIP file.
2. Keep index.html and hema_birthday_animation.gif in the same folder.
3. Open the folder in VS Code and run index.html with Live Server, or double-click index.html.

The birthday animation is stored locally, so it does not need an internet connection to load.
